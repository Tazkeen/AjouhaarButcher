## Introduction

Ajouhaar Moslem Butchery is a mobile sales and stock-management prototype for a butchery team. The repository contains an Android application written in Kotlin, an ASP.NET Core API and a guarded utility for simulated Firestore data. Firebase Authentication provides staff identity and Cloud Firestore stores shared staff and business records.

## Problem and purpose

Shop staff need to find product prices, record customer purchases and keep stock information current. Manual calculation and separate records can create errors or delays. The project brings product lookup, payment recording, receipt calculation and inventory changes into a mobile workflow with role-specific permissions.

## Objectives

- Provide a phone-based application for cashier sales and manager administration.
- Store products, sales, sale line items, staff profiles and stock movements in a shared database.
- Validate sale quantities, stock availability and payment values.
- Limit staff administration and selected inventory/report operations to managers.
- Support Firebase login and Google SSO for pre-linked active staff.
- Build and test Android code through GitHub Actions.
